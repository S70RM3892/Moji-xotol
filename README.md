# Moji-Xolotl

大学受験の英単語（共通テスト〜京大）で遊ぶ、文字タイル式の単語パズル。
袋から来る文字を1枚ずつ盤面に置き、次に来る文字に賭けながらお題の英単語を組み上げる。
見た目は壁画調。アイコンとホームの絵は `assets/xolotl.webp`。

## 遊ぶ形は5つ

- **刻む**: 手札の文字をドラッグして、壁に語を並べる（下の「ルール」）
- **喰らう**: 壁いっぱいに並んだ文字の中で文字食い邪神を矢印ボタンで動かし、お題の語をつづりの順に食べさせる
- **粗読み**: 文章を1題、時間を計って通読し、要旨を選ぶ（下の「粗読みモード」）
- **読み解く**: 英文を1文読み、同じ意味の英文を選ぶ。訳さずに英語のまま意味を取る練習（下の「読み解くモード」）
- **読む**: 英単語を見て意味を即答する。長文を速く読むための練習（下の「読むモード」）

ホームの「過去問の分析データを見る」から、下の分析の表と、覚える価値の高い順の語の一覧（検索つき）を見られる。

刻む・喰らうは学習の流れが同じ（見る → 思い出す）で、覚えた語・復習待ちの記録を共有する。

### 喰らうモード

- 邪神の隣から、つづりどおりにたどれる道が必ず1本だけ通っている（`src/core/eater.ts` の `layout`。60通りの種で全お題を検証するテストあり）
- 正しい文字のマスへは進めて、食べたマスは空く。違う文字には進めず、命が1つ減る（1語につき3つ）
- 道のすぐ横には、次の1文字と取り違えやすい文字（母音どうし、l と r、c と k など）を置く。お題の文字は道の横には置かない
- 操作は矢印ボタン、キーボードの矢印、壁の上のスワイプ

## ルール（刻むモード）

- お題は1語ずつ出る。その語の文字が手札（7枚）に届くので、ドラッグして壁の好きな場所に並べる
- **初めての語は、まずつづりを見ながら作る（知る）。別の語を1つはさんで、同じ語がつづりなしでもう一度出る（思い出す）**
- 思い出すお題は、和訳・字数・頭文字が手がかり。ヒントで1文字ずつ見える。自力で作ると3倍、ヒントを使うと1.5倍、見ながら作ると1倍
- 置いた文字を含む英単語が縦か横にできれば得点。1枚で複数できると**連鎖**で、合計に連鎖数が掛かる（上限8倍）
- 札をつかむと、単語ができるマスが光る。マスの上では、できる単語と得点が出る
- 単語にならなかった文字（点線）は、何度でも動かせるし手札にも戻せる。要らない札は「すてる」へ運ぶ（4回）
- 達成したお題の語は壁から消え、字形だけが上に並ぶ（あとで思い出すときに写せないようにするため）
- ★は好きな文字になる。×2・×3マスに置いて単語を作るとその得点が倍になる
- 評価は、思い出すお題をヒントなしで作れた割合（全部 S / 7割 A / 4割 B）

## 学習の流れ

1. **知る**: 新しい語を、つづりを見ながら1文字ずつ並べる
2. **思い出す**: 同じ局の中で、意味と頭文字からつづりを思い出して並べる
3. **間を空ける**: 自力で思い出せた語は、後日の局につづりなしで再登場する（回数の少ない語から）
4. **覚え直す**: 思い出せなかった語は、次の局でもう一度「見ながら作る」から始まる

1局は新しい語3つ（+ 復習2語まで）で、6〜8題。

## やり込み

- **今日の盤 / 同じ盤をもう一度**: 並びが同じ盤を何度でもやり直せる。盤ごとに自己ベストが残る
- **護符**: 1局に2つまで持ち込む道具。レベルで増える。`src/meta.ts`
- **碑文**: 盤上の技を見つけると刻まれる22枚。条件は伏せてあり、謎かけだけが読める
- **単語図鑑**: 盤面で作った受験語が層ごとに貯まる

## モード

共テ重点 / 難関2次重点 / 京大重点。お題に選ばれる語の層の確率が変わる（`src/core/words.ts` の `MODE_WEIGHTS`）。
層の定義は 共テ = CEFR A1〜B1、難関2次 = B2、京大 = C1〜C2。ただし A1（中学初級）はお題に出さず、A2 もほとんど出さない。

| モード | 共テ | 難関2次 | 京大 |
|---|---|---|---|
| 共テ重点 | 60% | 30% | 10% |
| 難関2次重点 | 10% | 65% | 25% |
| 京大重点 | 0% | 25% | 75% |

むずかしさはお題の文字数を決める（短い語ほど易しいので下限を付けている）: やさしい 4〜6文字 / ふつう 5文字以上 / むずかしい 6文字以上。
上限は刻むモードが盤面の幅（8文字）、喰らうモードが10文字。

見ながら作るお題で「知ってる」を押すと、その語を覚えた語として記録し、別の新しい語に替える。

## 語の選び方（過去問の分析）

京大英語の過去問27年分（2000〜2026年度、延べ約2万3千語）と、共通テスト・センター試験の英語23年分（2004〜2026年度、延べ約7万4千語）を OCR で読み取って数えた（`scripts/analyze-exams.py`）。
OCR は語ごとに信頼度を出すので、信頼度75未満の語（京大で約16%、共テで約9%）は読み誤りの恐れがあるものとして数えない（`scripts/ocr-clean.py`）。問題文そのものはリポジトリに置かず、語ごとの集計値だけを `data/kyodai-words.tsv` と `data/kyote-words.tsv` に、表の要約を `src/data/analysis.json` に残している。

**1. 本文の語のレベル（延べ語数に占める割合）**

| 試験 | A1 | A2 | B1 | B2 | C1 | C2 | 表外 |
|---|---|---|---|---|---|---|---|
| 京大 | 63.2% | 15.8% | 10.4% | 4.3% | 0.6% | 0.3% | 5.3% |
| 共テ・センター | 71.4% | 15.0% | 8.1% | 2.2% | 0.2% | 0.0% | 3.1% |

京大の難所は B2 と、語彙リストにない学術語（subsequent, underlying, trajectory など）。C1・C2 は合わせて1%未満。共テの難所は B1。

**2. 一度出た語は、出にくくなるどころか、何倍も出やすい**

一般的な頻度が同じくらいの難語どうしで、ある年度に出る確率を比べた（京大、対象は2005〜2026年度）。

| 一般的な頻度 | 出たことがない | 1回出た（直近5年内） | 1回出た（6年以上前） | 2回以上出た |
|---|---|---|---|---|
| 3千〜8千位 | 0.43% | 2.78% | 2.87% | 8.08% |
| 8千〜2万位 | 0.22% | 2.14% | 1.61% | 5.12% |
| 2万位以下 | 0.09% | 0.78% | 1.19% | 3.41% |

同じ文章は二度と出ないが、論説文で使われる語は繰り返す。出たのが最近か昔かは、ほとんど関係がない。共テではこの傾向がさらに強い（1回出た語で2〜9%、2回以上で10〜21%）。

**3. 予測モデルと検証**

出題歴・一般的な頻度・語彙レベル・学術語らしい語尾（-tion, -ity, -ive など）・語の長さから「次の年度に出る確率」を見積もる。
2024年度までで学習し、設計にも学習にも使っていない2025・2026年度で検証した。

| 試験 | 予測上位1%の的中率 | でたらめに選ぶ場合との比 | 予測上位5%が拾う割合 |
|---|---|---|---|
| 京大 | 5.3% | 20倍 | 出た難語の41% |
| 共テ | 32.8% | 31倍 | 出た難語の70% |

**4. 出題への反映**

- 語ごとの覚える価値 = 次に出る見込み × まだ知らない見込み（ありふれた語ほど低い）
- 京大重点と共テ重点は、それぞれの価値が高い語から優先して出す。難関2次重点は語彙レベル（B2中心）で選ぶ
- 語彙リストにないが過去問に出た語を追加した（京大 390語、共テ 55語）
- お題と結果に「京大 2回（'12 '22）・共テ 3回」のように出題歴を出す

限界: 信頼度で落としきれない OCR の読み誤り、同じつづりの別の語（found = find の過去形 / 設立する）の取り違えがある。下線部和訳の箇所かどうかは区別していない。

## 和訳と品詞

和訳は品詞ごとに分けて出す（例: `[動] …を支える／…を持続する　[名] …`）。作り方は `scripts/build-glosses.py`。

- 品詞の一覧: CEFR-J / Octanove がその語に認めている品詞。そこにない語は Princeton WordNet 3.0 の品詞と使用頻度
- 訳語: ejdict-hand の語義を1つずつ品詞に振り分け、その語が持たない品詞の語義は捨てる
- 語義の順: WordNet の語義ごとの使用頻度（日本語 WordNet の訳語で ejdict の語義と突き合わせる）と、JMdict の逆引き（その英語を訳語に持つ常用の日本語）で、よく使う意味を前に出す
- ejdict にその品詞の訳がない語は JMdict の常用語で補う。それでも変な訳は `data/gloss-overrides.tsv` で直す

読むモードの選択肢は、同じ品詞の語の和訳から選ぶ。

限界: 機械的な突き合わせなので、入試で問われる意味が先頭に来ていない語が残っている。

## 読み解くモード（英語のまま意味を取る練習）

共テも京大の粗読みも、1語ずつ日本語に直していては時間が足りない。英語のまま意味を取れる文の難しさを、段階を踏んで上げていく。

- 英文が1文出る。意味をつかんだら「読めた」を押す（読むのにかかった時間から、1分あたりの語数を出す）
- 本文が隠れ、3つの英文から同じ意味のものを選ぶ。選択肢も英語なので、日本語を経由しない。読み返すと得点は半分
- 答えたあとに、その文の構文と骨組みの説明が日本語で出る
- 文は6段階: 基本の修飾 → 句で広げる（分詞・不定詞・前置詞句）→ 節を組み合わせる → 特殊構文（倒置・強調・仮定法・否定）→ 圧縮と省略（挿入・同格・省略）→ 京大型の長い一文
- 1分あたり120語（下の「読む速さの目安」）以上で正しく読めるのが2回続くと段階が上がり、間違えると下がる。段階は保存される

例文は `src/data/sentences.ts`。すべてこのゲームのために書いた文で、過去問の文は使っていない。いまは計138文（段階1〜3が各16文、段階4〜6が各30文）。正解の選択肢が3つのうち最も長くなる割合は、ほぼ3分の1にそろえてある（長さで当てられないように）。

## 粗読みモード（通読して要旨をつかむ練習）

目標の「本文を5分ほどで読んで内容をつかむ」をそのまま練習する。

- 英語の文章が1題出て、時計が動く。訳さず、戻らずに読み、「読み終えた」を押す
- 本文が隠れ、要旨を4つの英文から選ぶ（問1）。続けて、段落の役割や例の働きを問う3択に答える（問2）
- 要旨の誤答は「細部だけ」「言い過ぎ」「逆（否定されている通説）」の型で作ってある。答え合わせで、選択肢ごとに理由が出る
- 答え合わせには、読む速さ、日本語の要旨、段落ごとの役割が出る。そのうえで本文を読み直せる
- 長さは3段階: 短い（2段落・約170語）→ 中くらい（3段落・約270語）→ 京大型（6段落・約600語）。目安内で2問とも取れると上がり、要旨を外すと下がる
- 1分あたり450語を超える速さは、読まずに進めたものとして扱う（速さの加点も昇格もなし）

文章は `src/data/passages.ts`。すべてこのゲームのために書いたもので、過去問の文章は使っていない。いまは各段階4題、計12題。

### 読む速さの目安

京大の読解は大問2題で、1題はおよそ600語。手元の過去問（2016〜2026年度）のページごとの語数を数えると、2題の合計は平均約1,200語（1題あたり約490〜730語）。
Z会の分析でも、2025年度は大問Ⅰ約550語・大問Ⅱ約590語、2026年度は大問Ⅰ約730語・大問Ⅱ約580語とされている（[2025年度](https://www.zkai.co.jp/kyodai-exam/bunseki/eigo-2025/)、[2026年度](https://www.zkai.co.jp/kyodai-exam/bunseki/eigo/)）。
600語を5分で読むには1分あたり120語、730語なら約146語が要る。ゲームの目安は120語/分にしている。

## 読むモード（速く読むための練習）

目標は「本文を5分ほどで読んで内容をつかみ、残りを下線部訳に使う」こと。そのためには、難語を知っているだけでなく、見た瞬間に意味が出る必要がある。

- 英単語が1つ出て、4つの和訳から意味を選ぶ。1回20語
- 1.5秒以内に正しく答えたら「瞬時に読めた」。3回続けば「瞬時に読める語」に数える
- 間違えた語・遅かった語は次の回にもう一度出る
- 出る語は、選んだ層の過去問の本文に出た語が中心（難しい語、何度も出た語ほど出やすい）
- 選択肢は、同じ層・同じ品詞の語の和訳から選ぶ

このモードが鍛えるのは語の認識の速さ。構文を取る力は「読み解く」、要旨をつかむ力は「粗読み」で鍛える。仕上げは、実際の過去問を時間を計って読むこと。

## ここまでの経緯

最初は「袋から来る文字に賭けて、6語を同時に組む」ルールだった。自動プレイでは成立したが、人間には難しすぎた。
6語ぶんのつづりを覚えたまま、混ざって届く文字を仕分ける必要があったため。
いまは1語ずつに絞り、覚える負荷を「見て作る → 思い出す」の1語単位に下げている。

## 開発

```sh
npm install
npm run dev       # 開発サーバー
npm test          # テスト
npm run build     # dist/ に静的ファイルを出力
npm run dict      # data/raw から辞書を再生成
npm run artifact  # CSS・JS・判定辞書を1枚にまとめた artifact/moji-xotol.html を作る
```

データの出典とライセンスは [data/SOURCES.md](data/SOURCES.md)。
