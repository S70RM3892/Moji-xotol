# Moji-Xolotl

大学受験の英単語（共通テスト〜京大）で遊ぶ、文字タイル式の単語パズル。
袋から来る文字を1枚ずつ盤面に置き、次に来る文字に賭けながらお題の英単語を組み上げる。
見た目は壁画調。アイコンとホームの絵は `assets/xolotl.webp`。

## 遊ぶ形は2つ

- **刻む**: 手札の文字をドラッグして、壁に語を並べる（下の「ルール」）
- **喰らう**: 壁いっぱいに並んだ文字の中で文字食い邪神を矢印ボタンで動かし、お題の語をつづりの順に食べさせる

どちらも学習の流れは同じ（見る → 思い出す）で、覚えた語・復習待ちの記録を共有する。

### 喰らうモード

- 邪神の隣から、つづりどおりにたどれる道が必ず1本だけ通っている（`src/core/eater.ts` の `layout`。60通りの種で全お題を検証するテストあり）
- 正しい文字のマスへは進めて、食べたマスは空く。違う文字には進めず、命が1つ減る（1語につき3つ）
- 道のすぐ横には、次の1文字と取り違えやすい文字（母音どうし、l と r、c と k など）を置く。お題の文字は道の横には置かない
- 操作は矢印ボタン、キーボードの矢印、壁の上のスワイプ

## ルール（刻むモード）

- お題は1語ずつ出る。その語の文字が手札（7枚）に届くので、ドラッグして壁の好きな場所に並べる
- **初めての語は、まずつづりを見ながら作る（知る）。別の語を1つはさんで、同じ語がつづりなしでもう一度出る（思い出す）**
- 思い出すお題は、和訳・字数・頭文字が手がかり。ヒントで1文字ずつ見える。自力で作ると3倍、ヒントを使うと1.5倍、見ながら作ると1倍
- 置いた文字を含む英単語が縦か横にできれば得点。1枚で複数できると**連鎖**で、合計に連鎖数が掛かる（上限8倍）
- 札をつかむと、単語ができるマスが光る。マスの上では、できる単語と得点が出る
- 単語にならなかった文字（点線）は、何度でも動かせるし手札にも戻せる。要らない札は「すてる」へ運ぶ（4回）
- 達成したお題の語は壁から消え、字形だけが上に並ぶ（あとで思い出すときに写せないようにするため）
- ★は好きな文字になる。×2・×3マスに置いて単語を作るとその得点が倍になる
- 評価は、思い出すお題をヒントなしで作れた割合（全部 S / 7割 A / 4割 B）

## 学習の流れ

1. **知る**: 新しい語を、つづりを見ながら1文字ずつ並べる
2. **思い出す**: 同じ局の中で、意味と頭文字からつづりを思い出して並べる
3. **間を空ける**: 自力で思い出せた語は、後日の局につづりなしで再登場する（回数の少ない語から）
4. **覚え直す**: 思い出せなかった語は、次の局でもう一度「見ながら作る」から始まる

1局は新しい語3つ（+ 復習2語まで）で、6〜8題。

## やり込み

- **今日の盤 / 同じ盤をもう一度**: 並びが同じ盤を何度でもやり直せる。盤ごとに自己ベストが残る
- **護符**: 1局に2つまで持ち込む道具。レベルで増える。`src/meta.ts`
- **碑文**: 盤上の技を見つけると刻まれる22枚。条件は伏せてあり、謎かけだけが読める
- **単語図鑑**: 盤面で作った受験語が層ごとに貯まる

## モード

共テ重点 / 難関2次重点 / 京大重点。お題に選ばれる語の層の確率が変わる（`src/core/words.ts` の `MODE_WEIGHTS`）。
層の定義は 共テ = CEFR A1〜B1、難関2次 = B2、京大 = C1〜C2。ただし A1（中学初級）はお題に出さず、A2 もほとんど出さない。

| モード | 共テ | 難関2次 | 京大 |
|---|---|---|---|
| 共テ重点 | 60% | 30% | 10% |
| 難関2次重点 | 10% | 65% | 25% |
| 京大重点 | 0% | 25% | 75% |

むずかしさはお題の文字数を決める（短い語ほど易しいので下限を付けている）: やさしい 4〜6文字 / ふつう 5文字以上 / むずかしい 6文字以上。
上限は刻むモードが盤面の幅（8文字）、喰らうモードが10文字。

見ながら作るお題で「知ってる」を押すと、その語を覚えた語として記録し、別の新しい語に替える。

## 京大重点の語の選び方（過去問20年分の分析）

京大英語の過去問（2005〜2024年度）を OCR で読み取り、約1万8千語を数えた（`scripts/analyze-exams.py`）。

**1. 本文の語の9割は B1 以下。難しいのは B2 と、語彙リストにない学術語**

| レベル | A1 | A2 | B1 | B2 | C1 | C2 | 表外 |
|---|---|---|---|---|---|---|---|
| 延べ語数に占める割合 | 62.9% | 15.8% | 10.5% | 4.3% | 0.6% | 0.2% | 5.6% |

C1・C2 の語は合わせて1%未満。20年間に出た C1・C2 の語は113語だけで、B2 は413語、表外の難語は563語（subsequent, underlying, trajectory, indigenous など）。
「京大水準 = C1・C2」という最初の決め方は外れていた。

**2. 一度出た語は、出にくくなるどころか、何倍も出やすい**

一般的な頻度が同じくらいの難語どうしで、ある年度に出る確率を比べた（対象は2010〜2024年度）。

| 一般的な頻度 | 出たことがない | 1回出た（直近5年内） | 1回出た（6年以上前） | 2回以上出た |
|---|---|---|---|---|
| 3千〜8千位 | 0.43% | 3.19% | 3.61% | 6.95% |
| 8千〜2万位 | 0.22% | 2.08% | 1.84% | 5.80% |
| 2万位以下 | 0.09% | 1.18% | 1.06% | 4.12% |

同じ文章は二度と出ないが、京大が選ぶ論説文で使われる語は繰り返す。出たのが最近か昔かは、ほとんど関係がない。

**3. 予測モデル**

出題歴・一般的な頻度・語彙レベル・学術語らしい語尾（-tion, -ity, -ive など）・語の長さから「次の年度に出る確率」を見積もる。
2010〜2019年度で学習し、2020〜2024年度で検証した。予測上位1%の語は、でたらめに選ぶ場合の17倍、上位5%は8.5倍の割合で実際に出た。

**4. 出題への反映**

- 語ごとの覚える価値 = 次に出る見込み × まだ知らない見込み（ありふれた語ほど低い）
- 京大重点は、この価値の高い語から優先して出す。出題の約8割が過去問に出た語になる
- 語彙リストにないが過去問に出た語309語を、京大層の語として追加した
- お題と結果に「京大過去問 2回（'12 '22）」のように出題歴を出す。ホームに、過去問の難語714語のうち覚えた数を出す

限界: OCR の読み誤り、同じつづりの別の語（found = find の過去形 / 設立する）の取り違えがある。下線部和訳の箇所かどうかは区別していない。

## ここまでの経緯

最初は「袋から来る文字に賭けて、6語を同時に組む」ルールだった。自動プレイでは成立したが、人間には難しすぎた。
6語ぶんのつづりを覚えたまま、混ざって届く文字を仕分ける必要があったため。
いまは1語ずつに絞り、覚える負荷を「見て作る → 思い出す」の1語単位に下げている。

## 開発

```sh
npm install
npm run dev       # 開発サーバー
npm test          # テスト
npm run build     # dist/ に静的ファイルを出力
npm run dict      # data/raw から辞書を再生成
npm run artifact  # CSS・JS・判定辞書を1枚にまとめた artifact/moji-xotol.html を作る
```

データの出典とライセンスは [data/SOURCES.md](data/SOURCES.md)。
